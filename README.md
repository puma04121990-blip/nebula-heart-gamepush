# Сердце Туманности

**«Сердце Туманности»** — оригинальная HTML5 idle-игра для GamePush и витрин VK Игр. Игрок настраивает живое космическое ядро, собирает звёздную пыль, строит орбиты, ловит аномалии и периодически запускает коллапс ради постоянной прогрессии. Проект не зависит от сборщиков и сторонних игровых движков: его можно загрузить в GamePush как обычный HTML5 ZIP-архив.

> Версия **2.0** сохраняет знакомую основу — центральное ядро и нижнюю навигацию «Орбиты / Коллапс / Квант пыли» — но добавляет многоуровневую прогрессию, адаптацию под экран и оригинальное аудиосопровождение.

## Игровой цикл

Игра строится на трёх горизонтах. В короткой сессии игрок касаниями ядра собирает пыль, наращивает резонанс, ловит критические удары и закрывает временные разломы. В средней сессии он развивает орбиты, гармонии и сигналы, выполняет ежедневные контракты и отправляет экспедицию. В долгой перспективе игрок запускает коллапсы, получает осколки и ключи, а затем инвестирует их в постоянные исследования.

| Система | Роль в прогрессии | Где открывается |
| --- | --- | --- |
| Орбиты | Пассивный поток пыли и сочетания для «Хора орбит». | «Орбиты» → вкладка «Орбиты». |
| Гармонии | Сила настройки ядра и глобальные множители. | «Орбиты» → вкладка «Гармонии». |
| Сигналы | Автонастройка, прилив, частота разломов и критический шанс. | «Орбиты» → вкладка «Сигналы». |
| Созвездие дня | Три спокойные ежедневные цели; полный комплект выдаёт звёздный ключ. | Карточка статуса слева/сверху. |
| Экспедиции | Один активный маршрут, который создаёт отложенную награду и стимул вернуться. | Та же карточка статуса. |
| Исследования | Шесть постоянных узлов за ключи: поток, разломы, клики, окно резонанса, оффлайн-доход и награда коллапса. | «Орбиты» → «Исследования». |
| Коллапс | Престиж: сброс временной экономики за гравитацию и осколки. | «Коллапс». |

## Управление и доступность

Центральное ядро — единственный обязательный активный элемент: касайтесь его в ритме, чтобы удерживать резонанс. Три нижние кнопки не меняли порядок и назначение. Карточка статуса открывает контракты и экспедиции; меню содержит настройки, таблицу лидеров, социальные действия, документы и сброс.

Музыка не запускается автоматически: браузер разблокирует её после первого касания ядра. Пользователь может независимо отключить музыку, эффекты, вибрацию и декоративное движение. Это безопасно для мобильных браузеров и соответствует ожиданиям игрока при рекламе, сворачивании или блокировке экрана.

## Запуск локально

Для быстрого просмотра откройте `index.html` в браузере. Без ключей GamePush игра работает через `localStorage`; в опубликованной версии GamePush сохранение будет синхронизироваться с облаком.

Для визуальной QA-проверки доступен **изолированный** режим `?demo=1`. Он создаёт развитое демонстрационное состояние и не записывает его в прогресс игрока. Этот параметр не нужен в публикации.

## Подключение GamePush

1. Создайте игру в [панели GamePush](https://gamepush.com/panel/projects/new/).
2. В `index.html` укажите `GP_PROJECT_ID` и `GP_PUBLIC_TOKEN`.
3. В разделе **Players → Player Fields** создайте поля `progress` типа String и `score` числового типа. GamePush сохраняет только поля, заранее заведённые в панели; после `player.set` требуется `player.sync()`.[1]
4. В **Allowed Origins** добавьте тестовый и боевой домены. При включённой защите источников площадка заблокирует незарегистрированный хост.[2]
5. Настройте таблицу лидеров по полю `score`. GamePush может автоматически создать глобальную таблицу при обращении из SDK.[3]
6. В разделе рекламы настройте preloader, sticky banner, rewarded и fullscreen согласно правилам площадок. Sticky баннер занимает нижнюю область, поэтому игра резервирует соответствующий safe area.[4]
7. Загрузите ZIP-архив в Game Hosting и подключите VK Игры и другие нужные площадки.

### Жизненный цикл SDK

Обёртка `js/gp-bridge.js` ждёт `gp.player.ready`, показывает preloader, запускает sticky banner и только затем отмечает игру готовой. Для совместимых платформ вызываются `gameStart()` и `gameplayStart()`. GamePush рекомендует начинать игру после загрузки и использовать `gameplayStart()`/`gameplayStop()` вокруг фактического игрового процесса.[2]

Обработчики GamePush и браузера ставят игру и аудио на паузу при рекламе, сворачивании вкладки или блокировке устройства. Награда за rewarded-видео выдаётся строго после успешного ответа SDK; показывать rewarded-рекламу без награды запрещено.[4]

## Проверка перед публикацией в VK Играх

| Проверка | Что сделать |
| --- | --- |
| Учётные данные | Подставить настоящий Project ID и Public Token; не хранить приватные ключи в клиентском ZIP. |
| Поля игрока | Создать `progress` и `score`, проверить облачный вход с новой и существующей учётной записью. |
| Ориентации | Пройти первый запуск на смартфоне в портрете, затем развернуть его в альбомную ориентацию; проверить desktop. |
| Баннер | Убедиться, что sticky баннер не перекрывает нижний док на целевых источниках. |
| Реклама | Проверить rewarded через явную кнопку и fullscreen только после коллапса — не во время геймплея и не при навигации VK.[4] |
| Документы | Привязать политику конфиденциальности в GamePush и проверить пункт меню в боевой среде. |
| Витрина | Подготовить и проверить карточку игры, иконку, горизонтальные и вертикальные скриншоты, возрастную маркировку и описание в кабинете VK. |

## Сохранения и совместимость

Сохранение версии 2 содержит поле `version` и безопасно мигрирует данные оригинальной версии: пыль, орбиты, гармонии, сигналы, гравитацию, осколки, язык и прежнюю настройку звука. Новые данные — исследования, ключи, контракты, экспедиция, настройки и статистика — получают корректные значения по умолчанию. Оффлайн-доход ограничен и рассчитывается по устойчивым постоянным модификаторам.

## Лицензия и оригинальность

Код, визуальная атмосфера, тексты, названия механик и фоновая музыка созданы для этого проекта. Игра использует жанровые принципы idle/clicker, но не копирует исходные ассеты, код, брендинг или текст других игр.
