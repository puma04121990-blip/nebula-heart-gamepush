# Сердце Туманности

HTML5 idle-clicker для площадки [GamePush](https://gamepush.com).  
Репозиторий: игра, интеграция SDK и инструкция по публикации.

**Живой превью:** откройте `index.html` локально или залейте архив в Game Hosting.

---

## 1. Глубокий анализ оригинала

Источник: [VK Mini App «Эволюция Кота»](https://prod-app54693531-a22e4c874389.pages-ac.vk-apps.com/index.html).

### Жанр и целевая аудитория
- Жанр: idle / clicker с престижем.
- Возраст: **0+**.
- Сессия: короткие заходы + оффлайн-прогресс.
- Площадка: VK Apps (облачные сейвы, реклама, социальные кнопки).

### Экономика
| Элемент | Как устроено |
|---|---|
| Валюта | Рыбки |
| Активный доход | Клик по коту |
| Пассивный доход | Улучшения «рыбок в секунду» |
| Прогрессия | Покупка улучшений и шкала цен |
| Мета-цикл | Престиж: сброс текущего прогресса за постоянный множитель (с порога ~1 000 000 рыбок за всё время) |
| Монетизация | Rewarded по кнопке; fullscreen после престижа |
| Удержание | Оффлайн-начисление, лидерборд, избранное, инвайт друзей |

### UX / UI
- Тёмно-фиолетовый фон, эмодзи-кот и рыбки.
- Верх: валюта, скорость / сек, стадия эволюции и процент.
- Низ: Улучшения, Престиж, реклама, звук, меню.
- Онбординг: согласие + объяснение рекламы и облачных сейвов.
- Сохранение в облаке платформы.

### Что сильное
- Простой первый клик, понятный фидбэк «число растёт».
- Престиж даёт длинную цель.
- Rewarded не навязывается — только по кнопке.

### Что слабое / шаблонное
- Классический cookie-clicker без уникальной механики.
- Тема «кот + еда» очень распространёна.
- Эволюция — в основном скин и процент, а не новый геймплей.

## 2. Чем наша игра отличается (оригинальность)

**Сердце Туманности** — вы не кормите животное, а настраиваете **живую космическую станцию**: собираете звёздную пыль, раскручиваете орбиты и сжимаете ядро до сверхновой коллапса.

Уникальные отличия от оригинала:
1. **Тема** — космическая алхимия / туманность, а не кот.
2. **Резонанс** — серия кликов в ритме усиливает удар (комбо), а не просто +1 рыбка.
3. **Две линии улучшений** — Орбиты (пассив) и Гармонии (сила клика / множители).
4. **Коллапс** вместо «престижа кота»: сюжетный сброс в чёрную дыру с постоянной Гравитацией.
5. **Стадии ядра** меняют палитру, частицы и название сущности.
6. **Визуал** — темный космос, бирюза и магента, без эмодзи-кота.

Механически игра **аналогична** (клик, idle, шоп, мета-сброс, оффлайн, rewarded), но контент, тон и одна ключевая механика — свои.

## 3. GamePush: что изучено и как встроено

Документация: https://docs.gamepush.com/

### Обязательный жизненный цикл (уже в коде)
1. Подключить SDK с `projectId` и `publicToken` из панели.
2. Дождаться `gp.player.ready`.
3. `await gp.ads.showPreloader()` — только до старта.
4. `gp.ads.showSticky()` — нижний баннер, не перекрывает игру (UI с отступом снизу).
5. `gp.gameStart()` после загрузки.
6. `gp.gameplayStart()` / `gp.gameplayStop()` для площадок вроде Poki / CrazyGames.
7. Пауза игры на `gp.on('pause')` / `resume` (реклама, свертывание).

### Сейвы
- Основной прогресс пишется в кастомное поле игрока `progress` (строка JSON).
- Рейтинг: базовое поле `score` = целые очки от lifetime-пыли (лог-шкала), чтобы таблица лидеров сортировалась корректно.
- `gp.player.set` + `gp.player.sync()`.
- Fallback: `localStorage`, если SDK нет или поле ещё не создано в панели.

### Реклама (по правилам GP)
- Rewarded **только по кнопке** и только с наградой.
- Fullscreen **не во время геймплея** — после коллапса (как в оригинале после престижа).
- Пред показом проверка `isRewardedAvailable` / `isFullscreenAvailable`.

### Что **не** реализуется «с нуля в коде»
Это настраивается в панели GamePush, SDK подтянет сам:
- список площадок, баннеры, частота рекламы;
- создание полей игрока;
- авторизация площадки;
- платежи / товары (в игре пока нет IAP);
- шаблоны политики конфиденциальности (`gp.documents.open`).

В коде есть вызовы overlay-ов: лидерборд, документы, инвайт/шер (если метод есть на текущей площадке).

## 4. Подключение к вашему проекту GamePush

1. Создайте игру: https://gamepush.com/panel/projects/new/
2. Скопируйте **Project ID** и **Public Token**.
3. В `index.html` замените:
   - `YOUR_PROJECT_ID`
   - `YOUR_PUBLIC_TOKEN`
4. В панели → **Players** добавьте поле:
   - ключ: `progress`
   - тип: **String**
   - публичное: нет
5. В **Allowed Origins** добавьте хост теста и боевой хостинг.
6. Залейте ZIP в **Game Hosting** и привяжите площадки (Yandex, VK, CrazyGames и т.д.).
7. Рекламу и лидерборд настройте в панели — SDK сам выберет адаптер площадки.

Без токена игра **работает оффлайн** через localStorage (удобно для разработки).
